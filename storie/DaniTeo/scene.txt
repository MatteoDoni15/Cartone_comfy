# Scene della storia: un blocco per inquadratura, nell'ordine del cartone.
#
#   [id]          nome della scena; i file escono in output/DaniTeo/<id>_...png
#   immagine:     cosa si vede (inglese, una riga). {Teo} e {Dani} diventano la loro
#                 descrizione da personaggi.txt; i vestiti vanno scritti qui.
#   movimento:    cosa succede nella clip animata (inglese, una riga), per il video.
#   narrazione:   testo dei sottotitoli (italiano). Se non ci sono righe "parla:",
#                 è anche il testo letto dalla voce narrante.
#   parla:        Personaggio | battuta  -> letta con la voce del personaggio (voci in voce.py).
#                 Si può ripetere; se c'è, sostituisce la voce narrante in quella scena.
#   scritta:      testo da disegnare DENTRO l'immagine (facoltativo; senza, niente scritte).
#   formato:      LxA, facoltativo (default 1536x864 = 16:9, quello del video).
#   seed:         facoltativo, per rifare sempre la stessa immagine.
#
# Dopo ogni modifica: python prepara_storia.py storie/DaniTeo
